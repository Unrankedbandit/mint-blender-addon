# Changelog

## 0.1.0 - 2026-06-10

- Initial public release of the Mint Blender add-on.
- Browse Mint models, worlds, and asset packs from Blender.
- Import durable Mint GLB models into the current Blender scene.
- View Mint world splats through the Kiri Engine 3DGS Render add-on.
- Control imported splats with Render Mode, Point Cloud, Update View, and Auto
  Update controls.
